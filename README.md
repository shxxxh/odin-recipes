# Odin Recipes

This project is a basic recipe website built with HTML.

It contains a home page with links to three recipe pages. Each recipe page includes an image, a description, a list of ingredients, and cooking steps.

Through this project, I will practice creating HTML pages, adding links and images, using ordered and unordered lists, and organizing files into folders.this is where i will showcase of what ive learned from the html lesson this may look like an ordinary website but this is the beginning only
